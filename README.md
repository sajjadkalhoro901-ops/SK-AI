# SK AI

A separate personal AI assistant project for the SK AI experience.

## Vision

SK AI is designed as a voice-first, multilingual assistant that can answer general questions, search the web when needed, help with writing, translation, mathematics, coding, files and other permitted tasks, while asking for confirmation before sensitive actions.

## Current status

Foundation project initialized. The next phase is the assistant interface and secure AI backend connection.

## Security

Never commit API keys, passwords, OTPs, or other secrets to this repository. Use environment variables or a secrets manager for credentials.
